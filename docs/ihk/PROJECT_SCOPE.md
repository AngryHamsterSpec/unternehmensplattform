# Portfolio und möglicher IHK-Ausschnitt

Status: PLANUNGSHILFE. Kein Projektantrag, keine Zusage einer Anerkennung und kein Nachweis geleisteter eigener Arbeit.

Die gesamte Plattform ist das Portfolio-/Produktvorhaben. Ein späterer Prüfungsprojekt-Ausschnitt benötigt ein konkretes betriebliches Problem, abgrenzbaren Nutzen, nachvollziehbare Alternativen und einen tatsächlich durchgeführten Arbeitsumfang.

| Möglicher Ausschnitt | Geschäftliche Fragestellung | Messbarer Nachweis |
| --- | --- | --- |
| Entscheidungsmodul | Wie lässt sich eine Infrastrukturwahl für definierte Anforderungen begründen? | Nutzwertvergleich, Kostenannahmen, reproduzierbare Entscheidung |
| Datenqualität | Wie verringert ein nachvollziehbarer Bereinigungsprozess Datenfehler? | gemessene Fehler vor/nach, Lineage, Zeitaufwand |
| Prozessanalyse | Wo entstehen belegte Wartezeiten und wie wird Verbesserung geprüft? | Eventdaten, KPI-Auswertung, Messplan |
| Cloud-Kosten | Welche dokumentierten Ressourcen-/Betriebskosten können verbessert werden? | Quellen, Vergleich, begründeter Maßnahmenplan |

Eine spätere Dokumentation führt Projektkontext, Stakeholder, Ist-Zustand, Soll-Zustand, Anforderungen, Alternativen, Wirtschaftlichkeit, Planung, Umsetzung, Tests, Abnahme und Rückblick. Aktuell fehlen dafür reale Betriebsdaten, bestätigte Kosten und Arbeitsnachweise.

Der Eigentümer dokumentiert selbst ausgeführte Tätigkeiten, KI-Unterstützung und gelernte Entscheidungen ehrlich. Keine erfundenen Zeiten oder Formulierungen, die fremde Arbeit als eigene darstellen. Zuständige Kammer, Ausbildungsbetrieb und aktuelle Antragsbedingungen sind vor einer tatsächlichen Einreichung zu klären; Phase 0 enthält keine Rechts- oder Prüfungsordnungsauslegung.
